Как работает система?

  • Каждый студент получает уникальный QR-код
  • При входе в аудиторию студент сканирует QR-код
  • Система автоматически регистрирует посещение
  • Преподаватель видит статистику в реальном времени

Инструкции:

1. Отсканируйте QR-код студента с помощью камеры

2. Система автоматически распознает студента

3. Записывается в базу данных посещаемости
